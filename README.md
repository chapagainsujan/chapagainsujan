## R Packages (Developed / Maintained)

- **[transform](https://github.com/chapagainsujan/transform)**  
  Tests a numeric vector for normality, compares log, square-root, Box-Cox, Yeo-Johnson and rank-based inverse normal transformations, picks the best one, and lets you reverse it back to the original scale.
